## Decisions taken in this plan

- **No ORM, no Alembic.** `CREATE TABLE IF NOT EXISTS` in one `schema.sql` applied on every
  boot is the whole migration story. The spec's constraint is "no migration framework"; a
  `user_version` pragma is recorded so a future ticket can migrate if it ever needs to.
- **`queue_position` is a plain integer with gaps allowed**, reordered by rewrite rather than
  by shuffling neighbours. T-7 needs stable reordering; gap tolerance is cheaper than
  renumbering and is already promised in T-7's acceptance criteria.
- **Two alternates chosen: `nocturne` (dark) and `paperback` (light).** The base ships the
  system-following palette, so these give a real switch in both directions and prove the
  contract in both brightnesses — a single dark alternate would not exercise the light path.

## Out of scope, deliberately

No API beyond `/api/health`. No metadata calls. No carousel, queue, wheel, or archive. This
ticket ends with an app that boots, has a database, and looks like something.
