## Decisions

- **250ms debounce, and an in-flight request is abandoned when a newer one starts.** Without
  the abort, results can arrive out of order and the grid shows answers to a query the user
  has already finished typing past.
- **Delete does not evict cached artwork.** Files are content-addressed and two titles can
  legitimately share one image; reference counting is not worth it for files this small.
  Stated so it reads as a decision rather than an oversight.
