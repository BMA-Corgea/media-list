# T-6 — Title page

**Type** feature · **Risk** low · **Intent** T-1 · **After** T-4

Carries the games amendment (`kb/CURRENT-WORK.md`): outbound links and UI copy differ by
kind. T-5 registered `#/title/{id}` with a placeholder; this fills it.

## Acceptance criteria

1. **AC1 — the page reads as a page.** Backdrop as hero with a scrim, poster, title, year,
   kind, genres, summary, and the `why` shown as the user's own words.
2. **AC2 — anime shows both titles.** Where AniList supplied them, romaji *and* English
   appear (and the original-language title from TMDB). Not duplicated when they are equal.
3. **AC3 — the detail line is per kind.** Screen titles show runtime or episode count and,
   for anime, studio and season. Games show platforms and developer. No empty label is ever
   rendered.
4. **AC4 — the outbound link is per kind.** IMDb for screen titles, the IGDB game page for
   games. A title with neither shows **no link row at all** — never a dead link.
5. **AC5 — copy adapts to kind.** A game is *played*, not *watched*. The stored status stays
   `seen`; only the label changes.
6. **AC6 — `why` is editable in place.** Edit and save without leaving the page; the change
   persists across a reload. Clearing it stores `NULL`, not an empty string.
7. **AC7 — move to top of the queue.** The title becomes position 1 on the carousel, and
   the rest keep their relative order.
8. **AC8 — remove works and returns to the wall.**
9. **AC9 — a missing id is handled.** `#/title/999999` shows a real "not found" page, not a
   blank screen or a stack trace.
10. **AC10 — degrades with sparse data.** A title with no backdrop, no summary, no genres
    and no `why` still renders a page with no holes in the layout.

## Out of scope

Marking watched and the star rating (**T-9** — this page leaves the affordance to it),
reordering by drag (T-7), the wheel (T-8).
