# T-4 — Add a title: search-and-pick

**Type** feature · **Risk** medium · **Intent** T-1 · **After** T-3

The ticket T-1's success-shape item 1 is about, and the one with a stated failure condition:
*"if a user is ever asked to type a summary or paste an image URL, this has failed."*

## Acceptance criteria

1. **AC1 — one search, one click.** Typing shows candidate cards **with cover art**;
   clicking one stores the title with `title, year, kind, summary, poster, backdrop,
   genres, outbound link` all populated from T-3. Zero metadata typed.
2. **AC2 — the only typeable field is `why`.** Optional, one line, free text. No other input
   exists anywhere in the add flow. Verified by counting inputs in the DOM.
3. **AC3 — `media_type` is persisted.** The T-3 obligation in `kb/CURRENT-WORK.md`: a stored
   TMDB title carries its `media_type` in `detail`, so it can be refreshed later without the
   namespace ambiguity that returned the wrong film.
4. **AC4 — duplicates are refused kindly.** Adding a title already on the list returns 409
   naming the existing entry, not a stack trace and not a second row. Enforced by the
   `(source, source_id)` unique index, so a race cannot beat it either.
5. **AC5 — new titles land at the end of the queue.** `queue_position` = current max + 10
   (gap-tolerant, as T-7 requires); `status` = `queued`; `added_at` set.
6. **AC6 — search is debounced.** Typing "cowboy bebop" fires far fewer requests than it has
   characters. Measured, not assumed.
7. **AC7 — artwork is local.** The stored row's `poster_path`/`backdrop_path` are `/art/…`
   paths. No remote URL is ever persisted.
8. **AC8 — `GET /api/titles` lists what has been added**, newest queue order, so the add
   actually shows up.
9. **AC9 — a title can be removed.** `DELETE /api/titles/{id}` removes the row. Cached art
   is left alone (shared by content address; another title may use the same image).

## Out of scope

The carousel (T-5), the title page (T-6), reordering (T-7), the wheel (T-8), reviews (T-9),
CSV (T-10). This ticket ships an add view and a plain grid proving the add worked.
