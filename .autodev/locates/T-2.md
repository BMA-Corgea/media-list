## Risks found while locating

1. **The pre-paint script cannot be a module.** Vite defers `<script type="module">`, which
   would paint the default skin first and flash. The apply-stored-skin snippet must be an
   inline classic `<script>` in `<head>`, before any stylesheet-dependent paint. repo-tour
   solves this the same way.
2. **`data/` must exist before SQLite opens.** `sqlite3.connect()` on a path whose parent
   directory is missing raises rather than creating it. AC2 (delete `data/`, reboot) fails
   without an explicit `mkdir -p` in the bootstrap.
3. **SPA fallback must not swallow `/api`.** The catch-all route has to be registered after
   the API router and must exclude `/api/*`, or T-3's endpoints become HTML.
